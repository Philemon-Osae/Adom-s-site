### 🎯 Overview
Ghana's first booking platform for a trombonist. Built as a white-label extension of the Kwamepapaa booking engine, re-engineered for brass instruments with an interactive trombone synthesizer.

This site solves a real problem: Trombonists in Ghana get booked by word-of-mouth only. Now Google can find Adom as "Trombonist Ghana" — he is #1 by default.

### ✨ Core Features

#### 1. TRY MY HORN — Interactive Brass Synth (GCTU Innovation)
- **12 Chromatic Keys:** C, C#, D, D#, E, F, F#, G, G#, A, A#, B
- **UX:** Tap to sustain brass tone, tap again to stop + yellow glow active state
- **Tech:** Web Audio API with `AudioBuffer` + `GainNode` for realistic trombone sustain
- **Reusability:** Same engine as Phil Jazzy Worship Pad — swapped pad/strings samples for trombone brass samples. Proves Component Architecture.
